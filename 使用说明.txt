提词器新版 v1.0.0（Windows 10/11 x64）
=========================================

使用方法
1. 双击“提词器新版.exe”。
2. 选择或拖入 TXT、DOCX、DOC 文件；导入后自动启用。
3. 将光标放到目标程序：
   - Ctrl+V：粘贴当前提示文字，并准备下一条。
   - Ctrl+C：回退一条，使上一条重新成为待输出内容。
4. 需要正常使用系统复制粘贴时，请先点击“暂停”。
5. 展开窗口后可以编辑、插入、删除、排序及指定下一条。

便携数据
- 程序会在自身旁边自动创建 data 文件夹，保存进度、队列修改和窗口位置。
- 移动到其他电脑时，将“提词器新版.exe”和 data 文件夹一起复制即可保留进度。
- 若不需要历史进度，可在程序退出后删除 data 文件夹；下次启动会自动重建。

注意事项
- 不需要安装 .NET 或 Microsoft Word，不联网，不写注册表。
- 仅支持 Windows 10/11 64 位。
- 程序启用时会接管其他普通程序中的 Ctrl+C 和 Ctrl+V；程序自身编辑区不受影响。
- 安全桌面或以管理员身份运行的目标程序可能不接受普通权限程序的全局快捷键。
- 本程序目前没有商业数字签名；Windows 首次运行若出现 SmartScreen，可选择“更多信息”后“仍要运行”。
